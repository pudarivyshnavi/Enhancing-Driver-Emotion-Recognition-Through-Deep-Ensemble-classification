## 🧠 Overview

An advanced **AI-powered driver monitoring system** that detects and analyzes human emotions in real time using **computer vision and deep learning techniques**.

This project focuses on improving **road safety** by identifying driver states such as stress, fatigue, or distraction and enabling proactive intervention.

---

## 🎯 Core Features

- ✨ Real-time face detection & emotion recognition  
- 🎥 Live camera-based monitoring  
- 🧠 Deep ensemble classification model  
- ⚡ Fast and efficient prediction pipeline  
- 📊 Emotion insights & analysis  
- 🚨 Supports safety-focused applications

## 🧠 Model Architecture

This system uses a **Deep Ensemble Approach** combining:

- 📌 MobileNetV2 → Fast & efficient feature extraction  
- 📌 ResNet50 → Deep representation learning  
- 🔗 Ensemble Strategy → Improves prediction accuracy and robustness  

✔ Final prediction is generated by combining outputs from both models.
### 🔹 Models Used

- 🔥 MobileNetV2 (Lightweight CNN)
- 🔥 ResNet50 (Deep Residual Network)
- ⚡ Combined using Deep Ensemble Learning

**Core Concepts:**

* Computer Vision
* Deep Learning
* Machine Learning
* Ensemble Models
